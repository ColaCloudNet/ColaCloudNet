# Android：配置与使用

推荐客户端：**Clash Meta For Android**（ClashMFA）

Clash 是基于规则的跨平台代理核心；Clash Meta For Android 是其 Android 客户端。

## 一、下载

请从 [客户端下载站](https://colacloud.app) 或官网文档提供的链接获取当前推荐版本（文档示例版本号可能随官网更新）。

## 二、导入订阅

1. 用手机浏览器打开 [官网](https://colacloud.net)（若在微信 / QQ / 百度 App 内打开，请用系统浏览器打开）
2. 在仪表盘点击「一键导入 Clash 订阅」
3. 保存订阅并选中刚导入的配置文件

## 三、启动

点击启动后会在后台运行。首次使用会提示开启 VPN，确认即可。

## 四、验证

连接后用浏览器打开 `https://www.google.com.hk`。能打开则网络正常。
