# macOS：配置与使用

推荐客户端：**Mihomo Party**

## 一、下载

请从 [客户端下载站](https://colacloud.app) 下载对应芯片版本：

- Apple Silicon（M 系列）
- Intel

## 二、安装

1. 双击安装包，按提示完成安装
2. 安装过程中可能需要指纹 / 密码验证

## 三、导入订阅

1. 用浏览器打开 [官网](https://www.colacloud.net)
2. 在仪表盘点击「一键导入 Clash 订阅」，跳转到 Mihomo Party

## 四、启动

点击菜单栏 mihomo 图标，勾选「系统代理」后即可使用（必选）。

「虚拟网卡 / TUN」为增强模式，按需开启。

## 五、验证

连接后打开 `https://www.google.com.hk`。能打开则网络正常。
