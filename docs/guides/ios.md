# iOS：在 iPhone / iPad 上配置

推荐客户端：**Shadowrocket**

新手大约需要 3–10 分钟完成首次配置；配置一次后可持续使用。

## 系统与设备要求

- 系统：iOS 9.0 及以上
- 设备：iPhone、iPad、iPod touch，以及部分 M 系列 Mac（按客户端支持为准）

开始前请确认账号已有有效套餐。若没有，请登录官网购买套餐以获得可用订阅。

## 一、下载软件

1. 软件名称：Shadowrocket
2. 下载方式：App Store（官网登录后可在「苹果账号」页查看当前可用的下载说明；请确保订阅有效）
3. 下载完成后，请按官网说明切回你自己的 Apple ID

> 共享账号不保证长期可用。建议下载完成后立即退出共享账号。

## 二、导入订阅

1. 用 Safari 打开 [官网](https://colacloud.net)（若在微信 / QQ / 百度 App 内打开，请用系统浏览器打开）
2. 在仪表盘点击「一键导入 Shadowrocket」
3. 选择需要的节点，打开连接开关

首次连接会跳转 VPN 设置，需输入锁屏密码安装描述文件 / 证书，必须安装后才能使用。

## 三、验证

连接后在 Safari 打开 `https://www.google.com.hk` 测试。能打开则配置成功。

## 常见操作

- **更换节点**：订阅下方节点左侧小黄点表示当前节点，轻点目标节点即可切换。
- **查看流量与到期**：订阅名称下方显示已用上传 / 已用下载 / 总流量 / 到期时间。
- **全局代理**：将全局路由改为「代理」（不推荐）。默认「配置」会按规则分流（推荐）。
- **自动更新订阅**：Shadowrocket → 设置 → 订阅 → 自动后台更新。
