# Windows：配置与使用

推荐客户端：**Mihomo Party**

- 图形化客户端，内置 Clash.Meta（mihomo）内核
- 支持主题、覆写与配置修订
- 开箱可用的 TUN；集成 Sub-Store 便于管理订阅

## 一、下载

请从 [客户端下载站](https://colacloud.app) 下载对应系统版本：

- Windows 10 / 11：64 位默认版
- Windows 7 / 8：按官网提供的兼容版本下载

## 二、配置

1. 安装后打开 Mihomo Party（建议右键「以管理员身份运行」）
2. 若无响应：重启电脑，或在任务管理器结束 mihomo 相关进程后，再以管理员权限启动
3. 用 Edge / Chrome 打开 [官网](https://www.colacloud.net)
4. 在仪表盘点击「一键导入 Clash 订阅」，会跳转到 Mihomo Party

## 三、启动

打开「系统代理」后即可访问需要代理的网站（必选）。

「虚拟网卡 / TUN」为增强模式，按需开启其一即可。

## 四、验证

连接后打开 `https://www.google.com.hk`。能打开则网络正常。
